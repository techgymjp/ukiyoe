# 浮世絵職人

絵師・彫師・摺師、江戸の職人たちの作業工程をなぞって一枚の錦絵（浮世絵）を仕上げるWEBゲームです。

## 遊び方

| 工程 | 職人 | 操作 |
|---|---|---|
| 壱 版下絵 | 絵師 | 青い点線を筆でなぞって墨線を描く（速さで線に抑揚がつく） |
| 弐 色さし | 絵師 | 各部分に伝統の顔料（ベロ藍・紅・胡粉など）を指定する |
| 参 彫り | 彫師 | 左右反転した版木を、朱の印から線に沿って小刀で彫る。速すぎると線が欠ける |
| 四 摺り | 摺師 | 版ごとに「絵の具を置く → 見当合わせ → ばれんでこする → めくる」 |
| 伍 落款 | 絵師 | 雅号を入れて印を押し、完成。採点・画像保存・画廊に飾る・増し摺り |

各工程の出来栄えはそのまま完成した絵に表れます（筆跡＝主版の線、彫りの欠け、絵の具の掠れ・滲み、見当ずれ、摺りムラ、木目）。

画題は「月下夜桜」「霞富士帆影」「蓮池遊鯉」の3種（すべてオリジナル図案）。

## 実行

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで遊べます。

## GitHub Pages で公開

リポジトリの **Settings → Pages** で
- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)`

を選んで保存すると、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 構成

```
index.html      画面構成
css/style.css   スタイル
js/util.js      汎用関数・効果音（WebAudio）
js/designs.js   顔料と画題データ（SVGパス）
js/render.js    錦絵の描画エンジン（和紙・木目・摺りムラ・見当ずれ）
js/game.js      各工程のゲームロジック
```
